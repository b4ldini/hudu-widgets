▶ How this works — please read before you start

First, the words you'll see. Microsoft Intune is the system that will set up and look after your devices. It has its own names for things:

  • Device group — a set of devices that should all behave the same way, e.g. "staff laptops" or "the Year 5 iPad trolley". Everything in this tool hangs off these. You can have as many as you need.
  • Enrolment — how a device first joins Intune out of the box. Different device groups often need different methods, and a single group can have more than one.
  • User affinity — whether a device belongs to one named person or is shared. This one answer changes almost everything else, so it's asked first on every group.
  • Compliance policy — the health rules a device must meet to count as trustworthy (up-to-date, locked with a PIN, encrypted…).
  • Configuration policy — the settings we push out: Wi-Fi, security hardening, browser settings, what users may and may not change.
  • App deployment — software we install for you, either automatically or offered in a company app store on the device.

What to do:

  1. Answer the short scope questions (they open automatically the first time). We use them to lay out a realistic starting point rather than a blank page.
  2. Work through each device group. Press Open & edit on one to see everything in it. Correct the numbers, add or remove enrolment methods, compliance rules, configuration and apps. Add more groups if a set of devices needs to behave differently.
  3. List your apps and your Wi-Fi / network needs in the panels underneath, then tick them onto the device groups that need them.
  4. Add your people and groups so we know who each device group is for, and who will administer Intune.
  5. Watch the checker on the right. It flags things that genuinely bite later — a policy that will never apply to anyone, a rule that can't work on a shared device, a licence that doesn't include what you've asked for.
  6. Send it back to us. Use Copy as text and paste the whole thing into an email to your Active8 contact — replying to the message that sent you this link is perfect. It's a readable summary with a "plan data" code at the bottom that lets us reload your answers exactly. Please keep that code intact. Your draft also saves automatically in this browser.

Your device groups

Click a name to rename · Open & edit shows every setting for that group

One group per set of devices that should behave the same way. Split a group whenever the answer to “who uses this and how” changes — staff vs students, 1:1 vs shared, owned by you vs owned by them.

Apps — software that needs to be on the devices

List each app once, then tick it onto the device groups that need it

Include anything staff or students genuinely need: Microsoft 365, your MIS or line-of-business software, subject-specific software, printer drivers, VPN clients. Don't worry about how it gets installed — that's our problem, not yours.

Wi-Fi, VPN and certificates

Things the device needs before anyone can use it

If devices must join a particular Wi-Fi network automatically, reach an internal system over VPN, or trust an internal certificate, tell us here. On shared and single-purpose devices this matters a lot — nobody is there to type a Wi-Fi password.

People

Type each person once — after that you just click their name

Who we'll need to talk to, who will administer Intune, and who to use for the first test devices. A name or an email address is fine.

User groups — who each set of devices is for

Click names to put people in a group · the INT-… label is the technical name we'll create

Groups are how settings reach devices. Nothing applies to anybody until it's pointed at a group, so this section is what makes the rest of the plan real. You don't need to list every student individually — describe the group and we'll build it from your directory.
