Draytek 2865ax — firmware process

Monitoring

Active8 IT reviews the Draytek security advisory page and firmware release notes monthly. When a new version is published, it is recorded in the firmware version log and assessed for applicability and risk before scheduling deployment.

⚠ Deployment timing requirement — All Draytek firmware updates are performed outside Partou UK nursery operating hours (07:00–19:00, Monday to Friday). Preferred windows: weekday evenings (19:00–23:00) or weekends.

Pre-deployment checks

1
Review release notes
Full release notes are reviewed for known issues, breaking changes, or prerequisites before any firmware is deployed.
2
Confirm target version per site
The target firmware version is checked against the current version logged for each site in the firmware version log.
3
Identify pilot sites
Sites suitable for staged or pilot deployment are identified — typically lower-traffic or non-critical sites — to validate the release before wider rollout.
4
Confirm out-of-band access
ACS portal or direct IP access is confirmed to be available for each target device, ensuring recovery is possible if a device requires it.
5
Notify Partou UK Required
Partou UK's Infrastructure & Delivery Manager is notified at least 24 hours before any bulk deployment begins.

Deployment method — single site (direct web login)

Used where the ACS portal is unavailable or a single site requires a targeted update.

1
Log in to the router
Navigate to the router's management IP via browser and log in using the secure admin credentials held in the Active8 password vault.
2
Initiate firmware upgrade
Go to System Maintenance → Firmware Upgrade. Upload the verified firmware file or select Check for Update if internet access is available from the router.
3
Confirm and reboot
Confirm the upgrade. The router reboots automatically (typically 2–3 minutes). Verify the new firmware version is shown on the dashboard post-reboot.
4
Verify and log
Confirm connectivity is restored. Log the firmware version, date, and engineer in the firmware version log.

Deployment method — bulk (ACS portal)

Used for remote deployment across multiple sites.

1
Log in to the Draytek ACS portal
Navigate to the device list and filter for Partou UK 2865ax routers.
2
Select target devices
Select devices using a rolling (wave) approach — all 115 sites are never updated simultaneously.
3
Push the firmware update task
Schedule the update task for the approved out-of-hours window and initiate the push.
4
Monitor completion
The ACS dashboard is monitored for completion and failure status. Any failed deployments are investigated within 24 hours; retried or escalated as appropriate.
5
Log results
Final firmware version and update date are logged for each site in the firmware version log.

Rolling deployment — wave approach

To minimise risk across all 115 nursery sites, deployments are staged in batches. Each wave is held before proceeding to ensure stability.

Wave Batch size Criteria Hold before next wave
Wave 1 Pilot 2–3 sites Lower-traffic or non-critical sites 48 hours
Wave 2 Main ∼50 sites No issues found in Wave 1 24–48 hours
Wave 3 Final Remaining sites No issues found in Wave 2 N/A

Post-deployment verification

After each wave, the following is confirmed before proceeding to the next:

  • Router management page accessible and showing the correct firmware version
  • WAN connectivity and site internet access functioning normally
  • No alerts or errors visible in the ACS portal for updated devices
  • Firmware version log updated with current version, date, and engineer name

Record keeping — Draytek

A firmware version log is maintained for all 115 Draytek routers. Each record contains:

  • Site name and location
  • Device serial number / management IP
  • Current firmware version and previous firmware version
  • Date of last update
  • Deployment method used (direct / ACS)
  • Engineer who performed the update
  • Any notes or anomalies

Unifi Access Points — firmware process

✓ Automatic updates enabled — All Partou UK Unifi access points are configured to auto-update within the unifi.ui.com cloud controller on a weekly schedule, typically during low-traffic periods. Active8 IT verifies successful deployment during the monthly compliance check.

Monthly verification

Although updates are automatic, Active8 IT performs a monthly check to confirm all access points are on current firmware:

1
Log in to the cloud controller
Log in to unifi.ui.com and navigate to the Partou UK site group.
2
Review firmware column
Check the Devices list and firmware column for all access points. Confirm no devices show Update Available or a firmware error.
3
Investigate any exceptions
For any device not on the latest firmware: confirm auto-update is enabled, check for connectivity issues, and trigger a manual update if required.
4
Log the check
Record the firmware version and check date in the Unifi device log.

Manual update (exception only)

If an access point has not auto-updated within the expected window, a manual update is triggered:

1
Select the affected device(s)
In unifi.ui.com, locate and select the device(s) that have not updated.
2
Trigger manual firmware update
Click Update Firmware and confirm the target version.
3
Monitor and log
Monitor for successful completion and note the outcome in the compliance log.

Record keeping — Unifi APs

A monthly snapshot of all AP firmware versions is retained, including:

  • AP name and site location
  • Current firmware version
  • Auto-update status (enabled / disabled)
  • Last seen / last updated timestamp from the controller
  • Any manual interventions performed

SLA alignment & compliance reporting

SLA thresholds

Active8 IT operates within the SLA framework defined in the Partou UK Patching and Update Policy v1.0:

Time since release Active8 action Reporting
0–14 days Target: all devices updated within this window. Included in monthly compliance report.
14–30 days Device flagged; reason documented; accelerated remediation plan raised. Highlighted in monthly report to Partou UK.
30+ days Critical escalation to Partou Infrastructure & Delivery Manager; isolation risk assessed. Escalated immediately; included in monthly report with remediation timeline.

Monthly compliance report

Active8 IT produces and delivers a monthly compliance report to Partou UK's Infrastructure & Delivery Manager by the last working day of each calendar month. The report covers:

  • Total Draytek routers in scope vs. devices updated within SLA
  • Total Unifi APs in scope vs. devices confirmed on current firmware
  • List of any devices outside SLA, with reason and remediation action
  • Trend comparison against the prior month
  • Any incidents or anomalies related to firmware updates
  • Narrative summary of update activity, including links to vendor release notes
Reports are delivered by the last working day of each calendar month.

Exceptions & escalation

Where a firmware update cannot be applied within the standard SLA (e.g., known vendor bug, site access restriction, hardware fault), the following process applies:

1
Document the exception
The exception is recorded with full justification, including the reason the standard SLA cannot be met.
2
Notify Partou UK Within 5 working days
Partou UK's Infrastructure & Delivery Manager is notified within 5 working days of the exception being identified.
3
Agree a revised remediation target
A revised target date is agreed with Partou UK and tracked until the exception is resolved.
4
Report in monthly compliance report
The exception and its outcome are included in the next monthly compliance report.
