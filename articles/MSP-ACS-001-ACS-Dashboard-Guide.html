ACS Device Firmware
Dashboard & PDF Report Generator

A self-contained tool for importing, reviewing, and reporting on Draytek router firmware status across the Partou UK nursery estate. This guide covers exporting from VigorACS 3, using the dashboard below, and generating the monthly compliance PDF.

Purpose & prerequisites

The dashboard serves two purposes:

1
Operational review
Quickly identify offline devices, flag outdated firmware, and filter the estate by status during routine monthly checks.
2
Client reporting
Generate a branded, multi-section PDF compliance report for delivery to the Partou UK Infrastructure & Delivery Manager as part of the monthly patching cycle.

Prerequisites

RequirementDetail
ACS export fileDownloaded from VigorACS 3 as .xls or .xlsx
BrowserChrome or Edge recommended. An internet connection is required on first load (firmware version lookup).
ACS export cadenceExported monthly from VigorACS 3 via Monitoring → Devices. Export covers all CPEs in the Partou UK network group.
ℹ The dashboard does not store or transmit any data. All processing happens locally in the browser. The only outbound request is to the Draytek UK downloads page to check the latest firmware version.

Exporting from VigorACS 3

1
Log in to VigorACS 3
Navigate to the VigorACS 3 portal and sign in.
2
Open the Device Status report
Go to Monitoring → Device Status.
3
Select the correct network group
Ensure the Partou UK network group is selected before exporting.
4
Export as XLS
Click Export and choose XLS format. Save the file — the filename follows the pattern monitoring_devices_XXXXX.xls.

Using the dashboard

Drag the ACS export file onto the drop target below, or click Choose file to browse. The dashboard loads automatically once the file is selected.

Firmware version indicator

On load, the tool queries the Draytek UK downloads page and shows the latest recommended firmware version in the header bar:

IndicatorMeaning
● 4.5.2.2_BTVersion fetched live from Draytek UK. All firmware comparisons use this value.
● 4.5.2.2_BT (cached)Using a value fetched within the last 6 hours — no re-fetch needed.
△ input boxFetch failed. Type the version manually (e.g. 4.5.2.2_BT) and press Enter. The value is saved locally.

Monthly firmware review process

Complete the following steps once per calendar month, aligned with the Active8 IT patching schedule for Partou UK.

Step Action Output
1 Export device report from VigorACS 3 — Monitoring → Device Status → Export XLS. .xls file
2 Load the file into the dashboard above. Confirm the latest firmware indicator is green. Dashboard loaded with live firmware reference
3 Click Offline card. Review any offline devices. Log each in the firmware version log with reason. Offline device list noted
4 Click Outdated firmware card. Identify devices requiring patching. Cross-reference against the pre-deployment checklist in the Firmware Update Process guide. Patching target list
5 Complete firmware deployments via the ACS portal or direct login per the Firmware Update Process guide. Devices updated
6 Re-export from ACS after deployments. Load the new file into the dashboard to confirm compliance. Updated dashboard view
7 Click Export PDF. Set the sub-heading to include the review month (e.g. Monthly Review — May 2026). Leave subset on All. Click Download PDF. Compliance PDF generated
8 Deliver the PDF to the Partou UK Infrastructure & Delivery Manager by the last working day of the month. Monthly report delivered
⚠ If outdated devices remain after patching: document the exception with reason (e.g. device offline, vendor bug), notify the Partou UK Infrastructure & Delivery Manager within 5 working days, and include the exception in the monthly compliance report per the Firmware Update Process guide.
