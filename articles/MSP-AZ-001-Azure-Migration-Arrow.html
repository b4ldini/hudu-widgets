Process

Pre-Migration — Information Gathering
1
Identify the current distributor Azure Portal
Go to portal.azure.com → Home → Subscriptions → [Customer Subscription] → Billing → Billing profile invoices. The page will display a notice: "This subscription is billed to [Distributor] billing profile." Note the distributor name — this is required in the transfer request and you will need to contact them to approve the transfer.
2
Collect Tenant ID and Primary Domain Entra Admin Center
Go to entra.microsoft.com → Entra ID → Overview. From the Basic information panel, note:
  • Tenant ID — the GUID shown in the Tenant ID row
  • Primary domain — the .onmicrosoft or custom domain
  • Tenant Name — the display name of the organisation
3
Document existing resources and Subscription ID Azure Portal
Go to portal.azure.com → Resource groups → select the relevant resource group. From the Essentials panel note the Subscription ID (this is the old subscription from the current reseller). List all resources in the resource group — this forms the Resources to Transfer section of the Arrow email.
4
Check and download Reservations CSV Azure Portal
Go to Cost Management → Reservations + Hybrid Benefit. If reservations are listed, select all rows and click Download to export the CSV — attach this to the Arrow transfer request email. If the list is empty, note "N/A" in the transfer request.
⚠ Reservations are not automatically migrated. Where they exist, Arrow must re-purchase them under the new subscription after the transfer completes.
5
Download Cost Analysis CSV (last 12 months) Azure Portal
Go to Cost Management → Cost analysis → select Accumulated costs view → set date range to last 12 months → Download → select CSV → Download data. Attach this CSV to the Arrow transfer request email.
6
Confirm customer exists in Arrowsphere xsp.arrow.com
Log in to xsp.arrow.com. Confirm the customer is already set up under your partner account. If not, add them using their Primary Domain Name — this must exactly match the Entra primary domain noted in step 2.
7
Order Azure subscription for the customer xsp.arrow.comCritical
Go to Catalog → search Microsoft Azure Subscription (Azure Plan) → select Corporate type → add to cart → assign to the correct customer → checkout. Wait for the order status to show Fulfilled in the notification centre before proceeding.
⚠ Do not raise the Arrow transfer request until this order is confirmed as Fulfilled and the Subscription ID is visible on the Subscription Sheet.
8
Note the new Arrow Subscription ID xsp.arrow.com
Navigate to Manage → Customer's Services → select the customer → click the Microsoft Azure Subscription → Subscription Sheet → Consumption tab. Copy the Subscription ID shown in the panel. This is the New Arrow Subscription ID field in the transfer request.
9
Send transfer request to Arrow Email Action
Complete the form below and use Open in Mail to send to technical.ecs.uk@arrow.com. Arrow will raise the transfer request with Microsoft on your behalf. Attach the Reservations CSV and Cost Analysis CSV to the email.
Transfer Request
10
Notify current distributor to approve
Contact the current distributor (identified in step 1) and request they approve the transfer request. Inform the customer's service manager that the transfer has been initiated — they may need to communicate with their current provider.
⚠ Transfer requests are valid for 30 days. If the outbound distributor does not approve within this window, a new request must be raised.
Post-Transfer
11
Implement GDAP (Reseller + Arrow) Critical
Once transfer is confirmed, implement Granular Delegated Admin Privileges for both Active8 (reseller) and Arrow. This replaces the previous reseller's admin access.
12
Run Arrow Foreign Principle (PEC) scripts
Run the Arrow Foreign Principle scripts to establish correct billing attribution. Send a screenshot of the completed output to Arrow.
ℹ Euro billing environments use different Foreign Principle IDs — contact Arrow if this applies.
13
Remove previous reseller / distributor RBAC Critical
In portal.azure.com → Subscriptions → [Subscription] → Access control (IAM) → Role assignments, remove any Owner or Contributor entries belonging to the previous reseller or distributor. Verify no lingering service principals remain.
14
Review Reservations, Alerts and Thresholds
If reservations existed pre-migration, re-create them under the new Arrow subscription. Review cost alerts, budgets and thresholds in Cost Management — these do not carry over automatically.
15
Implement Partner Admin Link (PAL)
Link your MPN/partner ID to the customer subscription via PAL to ensure correct partner attribution for Azure credits and incentives.

Notes

  • Transfer requests are valid for 30 days. If the outbound distributor does not approve within that window, a new request must be raised.
  • The Subscription ID shown in the XSP Subscription Sheet (Consumption tab) is the new Arrow subscription ID — not the old one from the resource group essentials panel.
  • Reservations may not exist for all customers. Always check the Reservations + Hybrid Benefit page before assuming — if the list is empty, note N/A and skip the CSV. Where reservations do exist, they are not automatically migrated and must be re-purchased by Arrow under the new subscription after transfer.
  • Arrowsphere data may take several days to reflect correctly after a completed transfer.
  • Euro billing environments use different Foreign Principle IDs — contact Arrow if this applies.
  • If the Billing profile invoices page shows "Select a scope" rather than the distributor name, navigate directly to the subscription (not via Cost Management) and access Billing from the subscription blade.
  • Update this document after the first live run to reflect any corrections or additional steps.
