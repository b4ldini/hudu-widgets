Article Overview

This guide shows you how to take a batch of hotspot vouchers from the UniFi Network portal and turn them into a clean, print-ready voucher sheet you can send straight to the customer — using the Wi-Fi Voucher Redesigner, which is embedded in the middle of this article — read the steps first, then work in the tool without leaving the page.

The raw UniFi export is not customer-ready: the layout is plain, and its text layer is broken in a way that silently corrupts voucher codes if anyone copies them. The Redesigner repairs and verifies every code, then produces branded A4 voucher cards with cut lines. The Why This Tool section explains the problem in detail.

Takes 5–10 minutes
UniFi Network (HostiFi) portal
Runs entirely in your browser
A4 · 24 cards per page · cut lines
⚠
Never copy voucher codes out of the UniFi export

The export PDF looks fine, but its text layer drops every zero and dash — 57908-78437 copies out as 579878437 with no visible error. Codes taken from the raw export by copy-paste will not work for the customer. Always run the export through the Voucher Redesigner, which repairs and verifies each code.

1
Step 01 of 05
Find (or Create) the Vouchers in UniFi
1

Sign in to the customer’s UniFi Network controller (e.g. m038657.hostifi.com) and select the correct site if more than one is listed.

2

Open Hotspot Manager from the left-hand menu (the ticket icon — on older versions it lives under Insights > Hotspot).

3

Go to the Vouchers tab. Existing voucher batches are listed here.

4

If you need new vouchers, click Create Voucher and set the amount, expiry (e.g. 8 hours), usage type, and any bandwidth or data limits, then confirm.

ℹ
Match the limits to what the customer expects
The expiry and speed limits you set here are what the network actually enforces — the text printed on the voucher cards later is just a label. Make sure the two agree.
↓
2
Step 02 of 05
Export the Voucher List to PDF
1

In the Vouchers tab, select the batch you want to send out and choose Print (the printer icon next to the batch, or the print option after selecting the vouchers).

2

Your browser’s print dialog opens. Set the destination to Save as PDF — don’t send it to a physical printer.

3

Click Save and keep the file somewhere easy to find (the filename usually looks like m038657.hostifi.com - UniFi Network.pdf).

⚠
The saved PDF will look right but copy wrong

This is expected — it’s the broken text layer described at the top of this article. Don’t try to fix it, retype codes, or copy them anywhere. Just feed the whole PDF to the Redesigner in the next step.

↓
3
Step 03 of 05
Load the Export into the Voucher Redesigner
1

Scroll down to the Wi-Fi Voucher Redesigner embedded in the middle of this article — or, if you’d like more room, open it in its own tab.

2

Drag the exported PDF onto the box labelled “Drop the voucher export here”, or click the box to browse for it. You can drop several files at once — results are merged and de-duplicated.

3

Wait for the progress bar to finish. The tool reads the PDF’s text layer and re-reads each code from the page image, then cross-checks the two — this is what makes the codes trustworthy.

ℹ
Photos and code lists work too
The tool also accepts photos or screenshots of vouchers (PNG/JPG) and plain code lists (CSV/TXT). Codes from images can’t be independently verified, so the tool flags them — prefer the PDF export whenever you can.
↓
4
Step 04 of 05
Review the Codes
1

Check the badge next to “Review codes”. A green 10 of 10 verified means every voucher in the export was found and independently confirmed — you’re good to continue.

2

If the badge is amber, read the warning box above the code list. It tells you exactly what happened — duplicates it ignored, or vouchers it couldn’t fully read.

3

For any voucher the tool couldn’t read, the warning lists the digits it does know and the page number. Find that voucher in the original export (the digits appear in order, with zeros somewhere between them), then type the full code into the list — one code per line.

4

The code list is fully editable. Every non-empty line becomes one voucher card, so you can also remove codes you don’t want to send.

⚠
Don’t generate until the count is right

If the badge shows fewer codes than the export contains, a voucher is missing — the customer would receive a sheet with a voucher short. Resolve every warning before moving on.

↓
5
Step 05 of 05
Set the Details, Generate & Send
1

Under Voucher details, set the Network name (SSID) to the customer’s guest network (e.g. AAF-GUEST) and the Validity line (e.g. Valid 8h).

2

Update the Download, Upload and Data lines to match what you configured in UniFi (e.g. Download 20 Mbps · Upload 5 Mbps · Unlimited data).

3

Click Download redesigned PDF. You get an A4 sheet of clean voucher cards — 24 per page, each with the Wi-Fi name, code, validity and speeds, with dashed cut lines between cards.

4

Open the PDF and give it a quick visual once-over, then email it to the customer (or print and hand over). They can cut the sheet into individual vouchers for their guests.

Worth Knowing
Why Not Just Send the UniFi Export?
The Broken Text Layer, Explained

The UniFi export renders correctly but reads wrongly

In UniFi’s voucher export, the characters 0 (zero) and - (dash) are drawn on the page but missing from the PDF’s text layer. Anything that trusts the text — copy-paste, “export to Excel”, simple PDF readers — silently mangles the codes.

The Raw UniFi Export
Fine to look at, unsafe to reuse
  • Copying 57908-78437 yields 579878437 — a code that will never work
  • Zeros and dashes vanish with no visible error
  • Plain, cramped layout with no network name on the card
  • Speed labels garble too (“20.0 Mbps” becomes “2. Mbps”)
The Voucher Redesigner
Verified codes, presentable cards
  • Reads each code twice — from the text layer and the page image — and only accepts codes where both agree
  • Tells you explicitly if any voucher couldn’t be verified, rather than guessing
  • Prints the Wi-Fi name, validity and speeds on every card
  • Clean A4 grid with cut lines, ready to email or print
🔒
Nothing is uploaded anywhere

The Redesigner is a single HTML file — all reading, checking and PDF generation happens inside your browser. Voucher codes never leave your machine; the internet connection is only used to fetch the tool’s libraries when the page loads.

If Something Goes Wrong
Troubleshooting

Common Problems & Fixes

Click any problem to expand the fix

The badge says fewer codes than the export contains
One or more vouchers couldn’t be read reliably. The warning box lists each one with the digits the tool could confirm and the page it’s on. Open the original export, find the matching voucher (its digits appear in the same order, with zeros inserted somewhere), and type the full code into the list manually. The count then updates.
Warning: “Some codes came from OCR alone… could not be independently verified”
You loaded a photo, screenshot, or scanned PDF — there’s no text layer to verify against, so the tool read the image alone. Compare the code list against the original carefully before generating, or better, go back to UniFi and save a proper PDF export (Step 2), which the tool can fully verify.
Warning about ignored duplicate reads
The same code appeared more than once across the files you dropped (for example, the same export loaded twice). The tool keeps one copy of each code — this is safe and needs no action.
The tool page won’t process anything / sits at “Starting…”
The tool loads its PDF and OCR libraries from the internet the first time it needs them. Check you’re online, then reload the page and drop the file again. Everything else runs locally.
The code text is smaller on some cards in the output PDF
Card text auto-shrinks so longer codes always fit inside the code box — this is by design and prints perfectly legibly.
I can’t find the Vouchers page in the UniFi portal
Voucher management moved between UniFi Network versions. Look for Hotspot Manager (ticket icon) in the left menu; on older controllers it’s under Insights > Hotspot. Vouchers also only exist on sites where the guest hotspot portal is enabled.
