Add your folders to OneDrive (do this once)
This puts your SharePoint folders into File Explorer — just like the old shared drive
  1. 1 In your web browser, open https://emmanuelhouseorg.sharepoint.com/sites/emmanuel-files
  2. 2 Open the Shared Documents library. You do not need to open individual folders — you can add the whole library in one go.
  3. 3 In the toolbar at the top (without opening a subfolder), click Add shortcut to OneDrive.
  1. 4 Done. The whole library appears in File Explorer under OneDrive - Emmanuel House, and you will see every folder you have access to inside it.
You only see the folders you have permission to — one shortcut covers them all.
Email a file to someone (e.g. a partner agency)
Now the library is in File Explorer, you can attach a file the normal way — two easy methods
▶  Way A — drag and drop (quickest)
  1. 1Open File Explorer → OneDrive - Emmanuel House → your folder.
  2. 2Start a new email in Outlook.
  3. 3Drag the file straight into the email.
▶  Way B — attach inside Outlook
  1. 1In the new email, click Attach File.
  2. 2Choose Browse This PC…
  1. 3Go to OneDrive - Emmanuel House → your folder → pick the file → Insert.
Good to know
A few things worth remembering about how your files work
  • Both methods send the actual file (a copy) — perfect for partner agencies and for uploading to websites.
  • Files stay online-only until you open them, and download automatically when you attach — so they don’t fill up your laptop.
  • Uploading to a website? Same idea — in the site’s Browse / Choose box, go to your OneDrive - Emmanuel House folder and pick the file.
